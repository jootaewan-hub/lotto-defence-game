# 달빛 수호대

Phaser와 TypeScript로 만든 난이도별 120웨이브 소환·합성 디펜스 게임입니다.

**최신 밸런스(2026-09-18)**: [변경 수치와 진행 규칙](docs/balance-2026-09-18.md)을 참고하세요. 아래의 이전 밸런스 수치보다 이 문서가 우선합니다.

## 실행

- `npm install`
- `npm run dev`
- 브라우저에서 `http://127.0.0.1:5173/lotto-defence-game/` 열기
- 테스트: `npm test`
- 배포용 빌드: `npm run build`

## 플레이

수호자 3명으로 시작하며 첫 소환 비용 30골드가 차감됩니다. 원정 시작을 누르면 수호자가 자동으로 공격합니다.

- **Q**: 일반 소환. **W**: 고급 소환. 수호대 정원은 200명입니다.
- 전장 유닛을 드래그해 이동하고, 클릭하면 사거리를 확인합니다.
- 동일한 수호자 3명을 모으면 다음 등급의 후보 3명 중 하나를 선택해 합성합니다. 일괄 합성은 무작위 후보를 선택합니다.
- 기사·마법사·사제를 모두 배치하면 전원 공격력이 15% 증가합니다.
- **E**: 현재 전장의 적을 3초간 빙결합니다. 게임 시간 기준 재사용 대기시간은 24초입니다.
- **Space**: 일시정지. 전투 배속은 1·2·3·5배와 운영자용 10배입니다. 다른 탭으로 이동하면 자동으로 일시정지합니다.
- 5웨이브 클리어마다 26종 축복 중 무작위 후보 3개를 제시합니다. 하나를 선택하면 정규분포형 주사위로 강화량이 확정됩니다. 축복은 이번 원정에 누적되며 새 원정에서 초기화됩니다. 최종 웨이브는 승리로 종료됩니다.
- **R**: 선택 타워 공격력 룰렛, **T**: 선택 타워 공격속도 주사위. 둘 다 +1~20%로 강화하며 약 0.65초 뒤 자동 적용합니다.
- 수호자를 선택하고 **공격력 룰렛 강화**를 누르면 골드로 공격력 +1~20%를 얻습니다. 기본 비용은 25G, 해당 수호자의 강화 횟수마다 15G씩 증가하며 할인 축복이 적용됩니다. 정원이 가득 차도 계속 강화할 수 있습니다.
- 합성하면 재료 3명의 공격력 강화 수치·강화 횟수·투자 골드를 합산해 계승합니다. 판매 시 투자 골드의 50%를 기본 판매가에 더해 돌려줍니다.
- 주사위 회전 중에는 전투가 멈추고 중복 결제가 차단됩니다. 공격력 룰렛·공격속도 주사위는 회전 0.45초 + 결과 0.2초 뒤 자동 적용됩니다. 축복은 결과 공개 후 적용 버튼으로 확정합니다. 획득한 누적 효과는 **원정 축복** 메뉴에서 확인합니다.
- 적은 경로를 순환합니다. 제한시간 종료 시 살아 있는 일반 적 6명당 내구도 1, 보스당 5를 잃습니다.
- 5웨이브마다 보스, 10웨이브마다 진보스가 등장합니다.
- 보통 → 나이트메어 → 헬 → Insane 순서로 각 120웨이브를 진행합니다. 난이도 전환 시 유닛·골드·장비·강화·축복·남은 내구도를 유지하고 1웨이브부터 다시 시작합니다. Insane 120웨이브에서 최종 승리합니다.
- 보통 대비 적 체력·방어력은 나이트메어 1.5배, 헬 2배, Insane 3배입니다. Insane은 일반 적·보스·진보스 모두 등장 수가 2배입니다.
- 원정 종료 시 성장 조각이 저장됩니다. 영구 성장과 유니크 유닛의 기존 저장 형식은 유지합니다. 진행 중인 전투 자체는 저장하지 않습니다.

효과음은 상단 소리 버튼으로 켭니다. 좁은 화면에서는 전장 아래에 편성 메뉴가 표시됩니다.

## 검증

`tests/game-systems.test.ts`는 기존 소환·합성·보스·성장 시스템을 검증합니다. `tests/tactics.test.ts`는 편성 보너스의 실제 피해량, 빙결 및 재사용 대기, 보상 선택 중 정지, 중복 수령 방지, 회복 상한, 수호대 정원, 패배 후 재시작을 검증합니다.

2026-09-16 브라우저 확인: 데스크톱 및 390px 모바일, 자산 로딩, 소환, 전투, 빙결, 일시정지, 5웨이브 보상, 후보 선택 합성, 성장 메뉴, 가이드. 패배·재시작 화면은 브라우저의 일시적인 테스트 조건으로 확인했습니다. 120웨이브 전체를 수동 플레이한 결과는 아닙니다.

## 전투 연출

- 기사 검기, 마법사 화염탄, 사제 성광탄과 유니크 전용 번개·독·빙결·시간·광폭 검기, 총 8가지 투사체를 사용합니다.
- 발사 시 방향 전환, 예비 동작, 반동과 복귀 동작이 적용됩니다. 병사 위치와 사거리는 바뀌지 않습니다.
- 등급이 올라갈수록, 유니크 레벨이 5단계씩 오를수록 궤적·위성 입자·충격파·타격 파편이 강화됩니다. 입자 수는 상한을 둡니다.
- 투사체는 대상 ID를 추적해 현재 위치에 도착합니다. 판정은 기존 시뮬레이션을 유지하고, 처치 대상의 그림은 마지막 투사체의 피격까지 잠시 유지합니다.
- 고속 배속에서도 투사체가 보이도록 연출 시간은 최대 3배로 압축합니다. 실제 전투는 선택한 배속으로 진행합니다. 일시정지하면 발사·비행·타격 연출도 정지합니다.
- `tests/combat-visuals.test.ts`에서 이동 표적 추적, 도착 지점 고정, 배속별 추적, 역할별 구분, 레벨별 강화와 이벤트 대상 ID를 검증합니다.


## 주사위 확률과 축복

공격력 주사위는 1~20의 정수 눈을 사용합니다. 평균 중심은 10.5, 표준편차는 3.8인 가우스 가중치를 1~20 범위에서 정규화한 이산 절단 정규분포입니다. 균등한 20면체 주사위와 달리 중간값이 자주 나오며 양끝도 나올 수 있습니다. 다른 축복은 각 능력치에 맞는 범위를 사용합니다. 공격속도·축복 주사위는 확률 분포 막대를 표시합니다. 공격력 룰렛도 같은 중간값 중심 확률로 결과를 정하며, 화면의 동일 크기 칸은 균등 확률을 뜻하지 않습니다. 애니메이션은 게임 난수를 소비하거나 결과를 다시 추첨하지 않습니다.

26종: 전체 공격력, 공격 속도, 치명타 확률, 치명타 배율, 사거리, 보스 피해, 방어 관통, 기사 피해, 마법사 피해, 사제 피해, 광역 반경, 독 피해, 유니크 기술 위력, 처치 골드, 웨이브 보급, 이자, 소환 할인, 강화 할인, 최대 내구도, 웨이브 회복, 성채 피해 감소, 결계 지속시간, 결계 재사용 감소, 유니크 경험치, 잭팟 확률, 유니크 소환 보정.

축복별 범위·누적 상한은 `src/game/upgrades.ts`에 정의합니다. 상한에 도달한 축복은 다음 후보에서 제외합니다. `tests/upgrades.test.ts`는 50,000회 분포 검증, 후보 중복 방지, 5웨이브 보상, 실제 공격·사거리·수입·결계 반영, 만원 편성 강화, 결제 보호 및 합성 계승을 검증합니다.


## 유일슈퍼유니크와 드래곤 장비

- 같은 유형의 **유니크 1 + 전설 3 + 영웅 3 + 에픽 3 + 10,000G**로 각성합니다. 희귀는 재료에 포함하지 않습니다. 유형별 동시에 1명만 보유할 수 있습니다.
- 궁수 재료를 모을 수 있도록 일반 등급부터 궁수 계열을 추가했습니다. 궁수·전사·마법사·사제 네 유형을 구분합니다. 기존 시간마도사는 지원 역할인 사제 유형의 유니크 재료입니다.
- 모든 재료의 공격력·공격속도 강화 및 투자 금액을 계승합니다. 슈퍼유니크도 처치 경험치로 최대 99레벨까지 성장하며 레벨 기록은 기존 저장 방식으로 유지됩니다.
- 공통 버서커: 5초간 공격력/공격속도 2배, 종료 후 3초 대기(8초 주기).
- 천궁 아스트라: 적 5명 동시 공격, 보스에 물리 피해 5배.
- 검성 레오니스: 적 5명 동시 검기, 보스에 물리 피해 5배.
- 화신 이그니스: 매 공격이 맵 전체 적에게 화염 피해.
- 성좌 세라피엘: 전체 타워 공격력/공격속도 30% 증가, 10초 유지 후 5초 대기(15초 주기). 여러 축복을 중복 곱하지 않습니다.
- 장비는 슈퍼유니크 1명당 3칸, 종류별 1개이며 구입 즉시 장착되어 자동 작동합니다. 기본 구매가는 각각 10,000G입니다. 장비와 골드 강화는 현재 원정에 귀속됩니다.

| 장비 | 기본 효과 | 강화 성공 시 |
| --- | --- | --- |
| 드래곤 무기 | 공격력 +200 | 공격력 +100. +7 이상은 매 표적 공격마다 방어 무시 마법 피해 1,000~100,000 추가 |
| 드래곤 반지 | 공격 시 10% 확률로 전체 적에게 마법 피해 100 | 전체 피해량에 100~1,000 무작위 추가 |
| 드래곤 신발 | 매 웨이브 공격속도 10~80% 무작위 부여(구매 즉시에도 적용) | 별도의 누적 속도 보너스 10~80% 추가 |

장비 공통 최대 +24. 목표 단계별 성공 확률은 +1~4 100%, +5~6 66%, +7~8 50%, +9 33%, +10~12 20%, +13~15 10%, +16~20 5%, +21~24 2%입니다. 비용은 +1~3 각 10,000G, +4부터 단계마다 10,000G씩 증가합니다(+24는 220,000G). 실패하면 비용만 소비하고 기존 등급과 능력치는 유지합니다. 무기 마법·반지 추가 피해·신발 보너스는 각 구간의 균등 정수 난수입니다.

2026-09-17 추가 검증: 합성·구매·+3 강화·자동 전투는 재료와 골드를 주입한 브라우저 테스트 상황에서 확인했습니다. 100명 편성의 시뮬레이션도 점검했습니다. 120웨이브 전체를 수동 플레이한 결과는 아닙니다.

## 진화 외형과 도감

- 전장 발밑 배지와 유닛 카드에 등급 진화 1~9단계를 표시합니다. 선택 정보에서는 현재 단계와 전체 진화 경로를 볼 수 있습니다. 유니크는 5레벨마다 증가하는 스킬 진화 단계도 표시합니다.
- 일반~희귀는 기본형, 에픽~전설은 새 정예형, 신화~불멸은 새 초월형 외형을 사용합니다. 각 단계마다 크기·어깨 장식·망토·광륜·빛 입자가 증가하며, 200명 편성에서도 단계별 크기 차이를 유지합니다.
- 유일슈퍼유니크 4종은 전용 이미지로 교체했습니다: 천궁 아스트라(수정 활), 검성 레오니스(사자 갑주), 화신 이그니스(용암 갑주), 성좌 세라피엘(천사 날개).
- 상단 **진화 도감**에서 네 유형의 단계별 외형과 최종 각성을 비교합니다. 슈퍼유니크는 별도 조합으로 각성합니다.
- 개발 서버의 `/lotto-defence-game/tests/evolution-preview.html`은 실제 GameScene으로 40명 단계 비교 및 200명 렌더링을 확인하는 저장 없는 시각 검증 화면입니다.

## 난이도별 전장 배경

보통은 기존 달빛 숲을 유지합니다. 나이트메어는 보랏빛 안개와 뒤틀린 숲, 헬은 용암과 불탄 성채, Insane은 붉은 공허 균열과 떠 있는 파편으로 변경됩니다. 난이도 전환 시 배경과 전장 제목이 자동으로 바뀌며, 새 원정에서는 보통 배경으로 복구됩니다. 경로와 배치 좌표는 유지합니다. 배경 SVG는 `generate-backgrounds.py`로 재생성할 수 있습니다.

## 궁극 타워: 무극신

**천궁 아스트라 + 검성 레오니스 + 화신 이그니스 + 성좌 세라피엘 + 20,000G**를 슈퍼유니크 각성 메뉴에서 합성합니다. 재료 4기는 소모되며 무극신은 동시에 1기만 보유할 수 있습니다. 골드 공격력·공격속도 강화와 투자 골드를 합산 계승합니다. 장비는 종류별 최고 강화 단계와 보너스 합계로 통합하며 드래곤 상점에서 계속 강화할 수 있습니다.

1. 무극 광폭화: 10초 주기 중 6초 동안 자신의 공격력·공격속도 3배.
2. 천상 지배: 전투 중 자신과 전체 타워의 공격력·공격속도 +50%. 사제의 +30% 축복과 중첩하지 않고 높은 효과만 적용합니다.
3. 무극·천지개벽: 첫 적 등장 시 발동하고, 이후 12초마다 전장 전체에 현재 공격력 12배의 방어 무시 피해를 줍니다. 보스 피해는 추가 2배이며 스킬 피해/보스 피해 축복이 적용됩니다. 공격 재사용시간은 웨이브 사이에 유지하며 보상 선택과 일시정지 중에는 흐르지 않습니다.

기본 공격은 사거리 260 안에서 5명을 타격하는 검기이며, 기본 공격력은 1,600입니다. 무극신은 일반 소환·등급 합성에 등장하지 않으며, 유니크 레벨 성장을 지원합니다. 태극 광륜·흑백 도포·부유 검 전용 SVG와 천지개벽 전장 이펙트를 사용합니다. 개발 서버의 `/lotto-defence-game/tests/ultimate-preview.html`에서 저장 없이 실제 합성·전투를 확인할 수 있습니다.
