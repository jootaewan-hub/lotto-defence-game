# 달빛 수호대

Phaser 3와 TypeScript로 만든 소환·합성 디펜스 게임입니다. 보통 → 나이트메어 → 헬 → Insane 순서로 난이도를 이어 가며, 각 난이도에 120웨이브와 별도의 보스 단계가 있습니다.

## 실행과 검증

- Windows에서는 [게임 실행.cmd](게임%20실행.cmd)를 더블클릭하세요. 첫 실행에 필요한 파일을 설치하고 게임을 브라우저로 엽니다. 게임을 하는 동안 명령 창을 열어 두어야 합니다.
- 브라우저가 자동으로 열리지 않으면 명령 창에 표시된 **Local:** 주소를 여세요. 5173 포트를 다른 서버가 사용 중이면 5174 등으로 바뀝니다. 이전에 저장한 5173 주소는 새 실행을 가리키지 않을 수 있습니다.
- 터미널로 실행하려면 `npm install` 후 `npm run dev`를 실행하세요.
- 전체 테스트: `npm test`
- 배포용 빌드: `npm run build`
- 저장 기록을 건드리지 않는 플레이 화면: `http://127.0.0.1:5173/lotto-defence-game/tests/playtest-preview.html` (개발 서버 전용)

## 플레이

- 수호자 3명으로 시작합니다. **Q**는 일반 소환, **W**는 고급 소환, **A**는 전설 소환입니다. 보유 골드와 편성 슬롯에 따라 선택합니다.
- 수호자를 클릭하면 능력치를 보고, 드래그해 배치를 바꿉니다. 같은 수호자 3명을 합성합니다. 신화 전까지는 같은 클래스로 진화하고, 신화→초월·초월→불멸은 4개 클래스 중 무작위입니다. 불멸 3기는 같은 클래스의 유니크로 합성됩니다.
- 일반 불멸·유니크 타워 1기를 선택해 1,000G로 같은 등급의 다른 클래스로 무작위 변경할 수 있습니다. 유니크는 클래스별 3기까지 보유할 수 있습니다. 같은 클래스·등급 구간 3기를 편성하면 24종 시너지 중 해당 보너스가 활성화됩니다.
- **등급별 자동배치**는 높은 등급부터 적 출현 지점 가까이 배치합니다. 슈퍼유니크와 무극신은 전장 중앙에서 생성되고 자동배치 때도 중앙에 모입니다. 아래 목록은 무극신·슈퍼유니크·유니크·불멸 순으로 보여줍니다.
- 목록에서 등급을 고르면 합성 가능 횟수와 재료 수, 판매 대상 수가 표시됩니다. **등급 판매**는 선택한 등급의 일반 타워만 일괄판매하며 슈퍼유니크와 무극신은 제외합니다.
- **R**과 **T**는 공격력·공격속도 룰렛입니다. 선택한 수호자로 비용을 내지만 효과는 선택한 수호자와 같은 유형의 타워에 적용됩니다.
- 전장 상단에는 해당 웨이브·보스 단계의 **권장 DPS**와 편성한 수호자의 **현재 추정 DPS**가 나란히 표시됩니다. 아래 카드에는 타워별 단일 DPS가 있습니다. 단일 대상 기본 공격과 치명타 기대값 기준이며 멀티샷의 추가 대상·광역·스킬 피해는 제외합니다.
- **E**는 전장의 적을 얼리는 달빛 결계, **Space**는 일시정지입니다. 전투 배속은 1·2·3·5배이며 개발 서버에는 운영자용 10·20·40·80배도 표시됩니다.
- 조작부의 **자동 전체** 버튼으로 진행·소환·강화·배치·제작을 한 번에 켜거나 끌 수 있습니다. 각 기능은 따로 조정할 수도 있습니다.
- 10웨이브마다 축복 3개 중 하나를 고릅니다. 자동 진행을 켜면 보상 선택과 다음 단계 시작을 처리합니다.
- 보스는 웨이브 사이의 별도 단계입니다. 5웨이브마다 중간보스, 10웨이브마다 보스, 20웨이브마다 진보스가 등장하고, 마지막 120웨이브 뒤에 최종보스가 등장합니다.
- 영구 성장과 유니크 레벨은 저장됩니다. 진행 중인 원정 자체는 저장되지 않습니다.
- 나이트메어부터 캠페인별 체력 증가 단계는 1.25배, 이동속도 단계는 1.075배입니다.

## 최종 각성

같은 유형의 유니크 1명과 전설·신화·초월·불멸 각 3명, 40,000G를 모으면 슈퍼유니크를 각성합니다. 궁수·전사·마법사·사제의 슈퍼유니크 4종과 20,000G를 모으면 무극신을 만들 수 있습니다. 드래곤 상점의 장비는 슈퍼유니크와 무극신에게 장착합니다.
