# 운영자 밸런스 기준표

이 문서는 운영자 확인용입니다. 게임 UI에는 직접 노출하지 않는 내부 밸런스 표이며, 현재 코드 기준 수치를 정리합니다.

기준 코드:
- 소환 확률: `src/game/systems.ts`
- 유닛 스탯: `src/game/units.ts`, `src/game/rarities.ts`
- 웨이브/HP: `src/game/waves.ts`, `src/game/simulation.ts`
- 방어력/피해 감소: `src/game/simulation.ts`
- 스킬 업그레이드: `src/game/skills.ts`

## 소환 확률

무료 소환은 일반 소환 확률표를 그대로 사용합니다. 차이는 비용만 0G입니다.

| 등급 | 무료/일반 소환 | 고급 기본 풀 |
|---|---:|---:|
| 일반 | 45.9% | 20.0% |
| 고급 | 25.5% | 28.0% |
| 희귀 | 14.3% | 22.0% |
| 에픽 | 8.2% | 14.0% |
| 영웅 | 4.1% | 8.0% |
| 전설 | 2.0% | 4.5% |
| 신화 | 0.0% | 2.5% |
| 초월 | 0.0% | 0.8% |
| 불멸 | 0.0% | 0.2% |

고급 소환은 먼저 5배 상향된 유니크 전용 추첨을 진행합니다. 유니크 미당첨 시에만 위 고급 기본 풀에서 일반 유닛을 추첨합니다.

| 유니크 | 고급 소환 1회당 확률 |
|---|---:|
| 폭풍궁수 | 2.50% |
| 역병술사 | 2.50% |
| 시간마도사 | 0.80% |
| 서리마녀 | 0.80% |
| 광전사 | 0.25% |
| 전체 유니크 | 6.85% |

유니크 확률 스킬은 위 확률 전체에 곱연산으로 적용됩니다. 7단계 누적 보너스는 +98%이며, 전체 유니크 확률은 최대 약 13.56%입니다.

소환 비용:
- 일반 소환 기본 비용: `10G`
- 고급 소환 비용: `일반 소환 비용 x 5`
- 일반 소환 비용 증가: 성공 소환 10회마다 기본 비용 `+1G`
- 소환 할인 스킬 적용: `round((10 + floor(성공소환수 / 10)) * (1 - 소환할인))`, 최소 `1G`
- 고급 소환은 할인 적용 후 일반 소환 비용의 5배입니다.

잭팟에서 무료 소환권이 나올 확률:
- 처치 잭팟 발생 확률: 기본 `2.5%` + 행운 스킬 + 잭팟 미발생 보정
- 잭팟 보상 중 무료 소환권 비중: `30%`
- 즉, 기본 상태의 처치당 무료 소환권 기대 확률은 `2.5% x 30% = 0.75%`입니다.

## 유니크 타워

유니크 타워는 기존 등급 확률 안에서만 등장합니다. 일반 소환은 신화 이상을 배제하므로 유니크 타워는 고급 소환에서만 등장합니다.

| 등급 | 유닛 | 능력 | 공격력 | 공격속도 | 공격범위 |
|---|---|---|---:|---:|---:|
| 신화 | 유니크 폭풍궁수 | 멀티샷: 최대 3명 동시 공격 | 82 | 560ms | 154 |
| 신화 | 유니크 역병술사 | 독 DOT: 3초 동안 0.5초마다 방어 무시 피해 | 48 | 760ms | 136 |
| 초월 | 유니크 시간마도사 | 둔화: 2.5초 동안 이동속도 45% 감소 | 54 | 840ms | 160 |
| 초월 | 유니크 서리마녀 | 빙결: 28% 확률로 0.9초 정지 | 64 | 1040ms | 142 |
| 불멸 | 유니크 광전사 | 광폭화: 공격 후 3.5초 동안 피해 x1.6, 공격속도 x1.45 | 145 | 740ms | 128 |

유니크 레벨:
- 범위: `Lv.1 ~ Lv.99`
- 저장 위치: `meta.uniqueUnitLevels`
- 최초 획득 시 `Lv.1`, 같은 유니크를 다시 획득할 때마다 `+1`, 최대 `Lv.99`
- 일반 소환은 신화 이상을 배제하므로 유니크 레벨업은 고급 소환 또는 합성 결과로 진행됩니다.

유니크 레벨 스탯 계산식:
- 공격력: `round(기본 공격력 x (1 + (Lv - 1) x 0.012))`
- 공격속도: `max(180, round(기본 공격속도 / (1 + (Lv - 1) x 0.0045)))`
- 공격범위: `기본 범위 + floor((Lv - 1) / 5)`

유니크 스킬 레벨 보정:
- 멀티샷: 기본 3타겟, `Lv.30`부터 4타겟, `Lv.70`부터 5타겟
- 독 DOT: 피해 비율 `18% + (Lv - 1) x 0.2%`
- 둔화: 이동속도 배율 `55% - (Lv - 1) x 0.2%`, 최소 35%
- 빙결: 확률 `28% + (Lv - 1) x 0.2%`, 최대 50%; 지속시간 `900ms + (Lv - 1) x 8ms`
- 광폭화: 지속시간 `3500ms + (Lv - 1) x 25ms`; 피해 배율 `1.6 + 최대 0.5`; 공격속도 배율 `1.45 + 최대 0.35`

- 진보스 스폰 수: 1마리

## 방어력 계산식

최종 피해:

```text
최종피해 = max(1, round(원피해 x (100 / (100 + 방어력))))
```

예시:
- 원피해 100, 방어력 10 -> `round(100 x 100 / 110) = 91`
- 원피해 100, 방어력 50 -> `round(100 x 100 / 150) = 67`
- 원피해 100, 방어력 100 -> `round(100 x 100 / 200) = 50`

범위 공격은 먼저 `원피해 x 0.75`를 적용한 뒤 방어력으로 다시 감소합니다.

## 유니크 유닛 경험치와 레벨업

유니크 유닛의 레벨과 경험치는 게임 종료 후에도 저장됩니다. 같은 유니크를 다시 소환하면 즉시 1레벨 상승하며, 처치 경험치 진행도는 유지됩니다. 최고 레벨은 99입니다.

필요 경험치:
- 다음 레벨 필요 XP: `round(80 + (현재레벨 - 1) x 20 + (현재레벨 - 1)^1.25 x 6)`
- Lv.1 -> Lv.2: 80 XP
- Lv.99: 최고 레벨, 추가 경험치 없음

처치 경험치:
- 기본 XP: `4 + floor((웨이브 - 1) / 5) + 몬스터등급 x 2`
- 일반 몬스터: 기본 XP x1
- 일반 보스: 기본 XP x5
- 진보스: 기본 XP x12
- 직접 공격, 광역 공격, 독 지속 피해의 마지막 타격 유니크에게 귀속
- 같은 종류의 유니크 유닛은 영구 레벨과 경험치를 공유

레벨당 능력치 증가:
- 공격력 배율: `1 + (레벨 - 1) x 0.008 + ((레벨 - 1) / 98)^2 x 1.75`
- 공격력은 Lv.1 x1.00, Lv.50 x1.8295, Lv.99 x3.534
- 레벨당 공격력 증가분은 초반 약 +0.82%에서 마지막 구간 약 +4.35%까지 점차 상승
- 공격속도 배율: `1 + (레벨 - 1) x 0.004 + ((레벨 - 1) / 98)^2 x 0.8`
- 공격속도는 Lv.1 x1.00, Lv.50 x1.396, Lv.99 x2.192이며 공격 간격은 최소 180ms
- 공격범위 보너스: `round(진행도 x 15 + 진행도^2 x 35)`, Lv.50 +16, Lv.99 +50
- 치명타 확률 보너스: `진행도 x 5%p + 진행도^2 x 20%p`, Lv.50 +7.5%p, Lv.99 +25%p
- 진행도: `(레벨 - 1) / 98`
- 공격속도·범위·치명타도 후반 레벨일수록 한 레벨의 증가량이 커짐

| 유니크 | Lv.1 공격력 | Lv.50 공격력 | Lv.99 공격력 |
|---|---:|---:|---:|
| 폭풍궁수 | 82 | 150 | 290 |
| 역병술사 | 48 | 88 | 170 |
| 시간마도사 | 54 | 99 | 191 |
| 서리마녀 | 64 | 117 | 226 |
| 광전사 | 145 | 265 | 512 |

| 유니크 | 공격 간격 Lv.1 -> Lv.99 | 범위 Lv.1 -> Lv.99 | 치명타 Lv.1 -> Lv.99 |
|---|---:|---:|---:|
| 폭풍궁수 | 560ms -> 255ms | 154 -> 204 | 24% -> 49% |
| 역병술사 | 760ms -> 347ms | 136 -> 186 | 16% -> 41% |
| 시간마도사 | 840ms -> 383ms | 160 -> 210 | 18% -> 43% |
| 서리마녀 | 1040ms -> 474ms | 142 -> 192 | 18% -> 43% |
| 광전사 | 740ms -> 338ms | 128 -> 178 | 28% -> 53% |

유니크 스킬 단계:
- 단계: `1 + floor(레벨 / 5)`, 최대 20단계
- 1단계는 Lv.1~4, 2단계는 Lv.5~9, 20단계는 Lv.95~99
- 단계가 오를 때마다 아래 고유 효과가 실제 전투와 정보창에 동시에 반영

| 역병술사 | 틱 피해 +1%p, 지속시간 +0.025초 | 18% / 3.0초 | 37% / 3.475초 |

| 광전사 | 피해 x0.025, 공속 x0.0175, 지속시간 +0.125초 | x1.60 / x1.45 / 3.5초 | x2.075 / x1.7825 / 5.875초 |

## 성장 조각 획득

성장 조각은 성공과 실패 양쪽에서 꾸준히 획득합니다.

- 일반 웨이브 클리어: `+1조각`
- 5웨이브 보스 클리어: `+3조각`
- 10웨이브 진보스 클리어: `+6조각`
- 60웨이브 전체 클리어 시 웨이브 보상 합계: `102조각`
- 패배 기본 보상: `2 + ceil(도달 웨이브 / 4)`
