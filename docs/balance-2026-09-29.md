# 2026-09-29 합성·편성 변경

- 같은 타워 3기 합성이 모든 일반 등급에 적용됩니다. 일반→신화까지는 클래스를 유지합니다. 신화→초월과 초월→불멸은 궁수·전사·마법사·사제 중 하나를 무작위로 뽑습니다. 불멸→유니크는 재료의 클래스를 유지합니다.
- 유니크 보유 제한은 전장 전체 2기에서 클래스별 3기로 변경했습니다. 해당 클래스가 3기 미만이면 다른 클래스의 유니크 보유 수와 관계없이 합성할 수 있습니다. 전설 소환과 유형 변경도 클래스별 한도를 지킵니다. 슈퍼유니크는 일반 합성 대상과 유니크 보유 수에서 제외합니다.
- 선택한 일반 불멸 또는 유니크 타워 1기를 1,000G에 같은 등급의 다른 클래스로 무작위 변경합니다. 강화 수치와 위치는 유지합니다. 슈퍼유니크·무극신은 대상에서 제외합니다.
- 같은 클래스·등급 구간 타워 3기마다 아래 시너지 1개가 활성화됩니다. 각 보너스는 수호대 전체에 적용되며 서로 합산됩니다. 기존 세 역할 편성 공격력 +15%는 아래 24종으로 대체했습니다.

## 드래곤 장비 강화

- 드래곤 무기 공격력: 기본 +100, 강화 누적 보너스는 `50 × 강화 단계 + 80 × max(0, 강화 단계 − 6)²`. +6은 총 +400, +7은 +530, +12는 +3,580입니다.
- 드래곤 무기 마법 피해: +1부터 매 공격에 방어 무시 피해 `10 × 강화 단계² ~ 1,000 × 강화 단계²`. +1은 10~1,000, +7은 490~49,000, +12는 1,440~144,000입니다.
- 드래곤 반지: +7부터 강화 성공 시 추가 피해 추첨값(50~500)에 `1 + 0.06 × (강화 단계 − 6)²`를 곱합니다. 발동 확률 10%는 유지합니다.
- 강화 비용·성공률·최대 +24와 드래곤 신발의 속도 효과는 그대로입니다.

## 자동배치

일반 타워와 유니크는 높은 등급부터 적 출현 지점에 가까운 전장 가장자리로 배치합니다. 같은 등급에서는 궁수·전사·마법사·사제 순서로 정렬합니다. 슈퍼유니크와 무극신은 생성 시 중앙에 놓이고, 자동배치에서는 중앙 구역에 모입니다.

## 궁수 멀티샷과 보스

- 유니크 폭풍궁수는 기본 3명에게 각각 기본 피해의 0.9배를 줍니다. 기존 5레벨당 연사 위력 +1.5%는 이 배율에 곱해지며, 35레벨부터 4명, 70레벨부터 5명을 공격합니다.
- 슈퍼궁수는 기본 5명에게 각각 공격력의 1.1배를 줍니다. 21·41·61·81·101레벨에 대상이 한 명씩 늘어 최대 10명입니다. 기존 보스 피해 5배는 유지합니다.
- 중간보스·보스·진보스·최종보스의 체력에 각각 2.7·5.8·6.4·3.2배를 추가하고, 나이트메어·헬·Insane에서는 난이도 단계마다 1.8배를 누적 적용합니다. 4개 난이도의 모든 보스 단계에서 권장 DPS가 직전 일반 웨이브보다 높도록 검증했습니다.
- 권장 DPS는 필요 공격량을 비교하는 지표입니다. 실제 120웨이브 플레이 난이도는 별도 기록으로 재확인해야 합니다.
