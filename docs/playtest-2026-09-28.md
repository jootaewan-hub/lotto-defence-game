# 플레이 검증 — 2026-09-28

Phaser/Vite 개발 서버에서 실제 화면을 조작했다. 별도 `tests/playtest-preview.html`을 사용해 기존 저장 기록에 영향을 주지 않았다. 데스크톱 1265×720, 모바일 390×844를 확인했다.

## 확인한 문제와 수정

1. 데스크톱 첫 화면에서 원정 시작 버튼이 아래로 밀렸다. 높이 720px에서 조작부가 전장 아래에 숨어 있었다. 전장 폭을 화면 높이에 맞추고 조작부를 배속/시작과 자동 기능의 두 줄로 배치해 첫 화면에 표시했다.
2. 배속·자동 기능 버튼이 이정표와 겹쳤다. 고정 높이를 제거하고 두 줄 높이를 확보했다.
3. 자동 소환·합성·강화 알림이 계속 전장 가운데 떴다. 반복 자동 작업 알림을 숨기고, 나머지 알림은 전장 오른쪽 아래의 작은 칩으로 옮겼다.
4. 완전 자동 플레이를 시작하려면 토글 다섯 개를 켜야 했다. `전체` 버튼으로 한 번에 켜고 끌 수 있게 했다.
5. 모바일에서 ×20 배속의 운영자 글자가 잘렸다. 450px 이하에서는 짧은 배속 숫자만 표시하고 설명은 툴팁과 접근성 이름에 유지했다.
6. 강화 룰렛이 강화 범위를 명확히 표시하고 같은 유형의 타워에만 적용되도록 조정했다.

## 시뮬레이션 결과

시드 20260928, 시작 수호자 3기, 영구 성장 없음, 자동 기능 다섯 개 활성, 40ms 고정 틱. 수동 입력 없이 일반 난이도 40웨이브에 도달했다. 유형별 강화로 변경한 뒤 측정한 시점의 성채 체력은 20/20, 골드 29, 수호자 39기, 축복 3개, 보스 단계 7회 완료였다. 자동 보상 선택과 보스 단계 통과는 동작했다.

이 결과는 한 시드의 연속 플레이 검증이다. 40웨이브까지 체력 손실이 없으므로 난이도 균형은 다른 시드와 수동 플레이 기록을 모아 판단할 필요가 있다. 이번 작업에서는 적 능력치를 변경하지 않았다.

Unity 플러그인은 이 TypeScript/Phaser 프로젝트를 직접 편집하는 도구가 아니다. 이번에는 설치된 Game Studio의 브라우저 게임 플레이테스트 및 UI 지침을 적용했다.

## 추가 편성 개선

유닛 아래 등급 표시는 작은 한 글자 배지로 바꾸고 유니크는 `U`로 표기한다. 데스크톱 필드 폭은 높이 720px 환경에서 약 513px에서 575px로 넓혔다. 첫 화면의 원정 버튼은 계속 보인다. 클래스별 모으기와 목록의 등급 우선 정렬을 분리했다. 등급별 합성 횟수·재료 수를 보여주며, 선택 등급 일괄판매는 슈퍼유니크·무극신을 건드리지 않는다. 캠페인 전환 배율은 체력 1.5→1.25, 속도 1.15→1.075로 완화했다.
